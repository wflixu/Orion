# Orion

**SQL-first + Derive + Codegen 类型安全的数据访问层 for MoonBit**

Orion 是一个采用 Mapper 模式的数据库访问层，灵感来自 MyBatis、sqlx、Prisma 和 SeaORM。它提供两种开发模式：

1. **SQL-first** - 从 SQL 文件生成类型安全的 MoonBit 代码
2. **Derive + Codegen** - 声明式 schema 定义，自动生成 Struct + CRUD

```
Orion = SQL-first / Derive + 类型安全 + Mapper 模式 + 工程化
```

## 特性

- 📝 **SQL-first** - SQL 是权威来源，代码从 SQL 生成
- 🔧 **Derive + Codegen** - 声明式 schema 定义，自动生成代码
- 🔒 **类型安全** - 编译时类型检查，运行时类型转换
- 🗺️ **Mapper 模式** - 一个 SQL 语句对应一个函数
- 🛠️ **CLI 工具链** - 代码生成、迁移管理、开发体验优化
- 🚀 **MoonBit 原生** - 编译为 native，使用 C runtime

## 快速开始

### 安装

```bash
moon add wflixu/Orion
```

### 模式一：SQL-first

创建 SQL 文件 `queries/user.sql`：

```sql
-- name: getUserById
-- description: Get user by ID
-- result: single
SELECT id, name, age FROM users WHERE id = ?;

-- name: createUser
-- description: Create a new user
-- result: last_insert_id
INSERT INTO users (name, age) VALUES (?, ?);
```

生成代码：

```bash
orion gen --input queries --output generated
```

### 模式二：Derive + Codegen（v0.2.0+）

创建 Schema 文件 `schema/user.schema.mbt`：

```moonbit nocheck
import orion/schema

let user_schema = schema("user")
  |> field("id", Int, [PrimaryKey, AutoInc])
  |> field("name", String, [NotNull, MaxLength(100)])
  |> field("email", String, [Unique, NotNull])
```

生成代码：

```bash
orion gen schema
```

生成的代码包含：
- `struct User` with `derive(Eq, Hash, FromJson, ToJson, Show)`
- CRUD 函数：`create_user`, `find_user_by_id`, `find_all_users`, `update_user`, `delete_user`
- Query Builder（可选）：链式查询构建

生成的代码（SQL-first 模式）：

```moonbit nocheck
// generated/user.mbt

struct User {
  id: Int
  name: String
  age: Int
}

struct UserMapper {
  db: Orion.Db
}

fn get_user_by_id(self: UserMapper, id: Int) -> Result[Option[User], DbError]
fn create_user(self: UserMapper, name: String, age: Int) -> Result[Int, DbError]
fn list_users(self: UserMapper) -> Result[List[User], DbError]
```

生成的代码（Derive + Codegen 模式）：

```moonbit nocheck
// generated/user.mbt
// @generated by Orion v0.2.0

/// User 数据模型
pub struct User {
  id: Int,
  name: String
} derive(Eq, Hash, FromJson, ToJson, Show)

// CRUD 函数
pub fn create_user(db: Db, name: String) -> Result[Int, DbError]
pub fn find_user_by_id(db: Db, id: Int) -> Result[Option[User], DbError]
pub fn find_all_users(db: Db) -> Result[List[User], DbError]
pub fn update_user(db: Db, id: Int, name: String) -> Result[Int, DbError]
pub fn delete_user_by_id(db: Db, id: Int) -> Result[Int, DbError]

// Query Builder（可选）
pub fn UserQuery::new(db: Db) -> UserQuery
pub fn UserQuery::where_id(self, id: Int) -> Self
pub fn UserQuery::where_name(self, name: String) -> Self
pub fn UserQuery::execute(self) -> Result[List[User], DbError]
```

### 使用示例

```moonbit nocheck
import wflixu/Orion

fn main {
  // 连接数据库
  let db = Orion.connect({
    url: "sqlite://app.db",
    pool_size: 10
  })
  
  // 创建 Mapper
  let user_mapper = UserMapper::new(db)
  
  // 查询用户
  match user_mapper.get_user_by_id(1) {
    Some(user) => println("User: \(user.name)")
    None => println("User not found")
  }
  
  // 创建用户
  let user_id = user_mapper.create_user("Alice", 25)?
  
  // 启用日志
  Orion.enable_log(db, Debug)
}
```

## CLI 命令

### 代码生成

```bash
# 生成代码（SQL-first 模式）
orion gen

# 指定输入输出目录
orion gen --input ./queries --output ./generated

# 监听模式（文件变化自动重新生成）
orion gen --watch

# 生成代码（Derive + Codegen 模式，v0.2.0+）
orion gen schema
```

### 数据库迁移（v0.2.0+）

```bash
# 创建新迁移
orion migrate create add_users_table

# 应用迁移
orion migrate up

# 回滚迁移
orion migrate down

# 查看迁移状态
orion migrate status
```

## SQL 语法

### 基本语法

```sql
-- name: 函数名（必填）
-- description: 描述（可选）
-- result: single | many | last_insert_id | affected_rows
YOUR_SQL_HERE;
```

### 参数

支持两种参数风格：

```sql
-- SQLite / MySQL 风格 (?)
SELECT * FROM users WHERE id = ?;

-- PostgreSQL 风格 ($1, $2...)
SELECT * FROM users WHERE id = $1 AND name = $2;
```

### 动态 SQL（v0.3.0+）

```sql
-- name: findUsers
-- description: Find users with optional filters
SELECT * FROM users
WHERE 1=1
[@if name]
AND name = ?
[@endif]
[@if min_age]
AND age >= ?
[@endif]
;
```

## 运行时 API

### 连接管理

```moonbit nocheck
// 基本连接
let db = Orion.connect({
  url: "sqlite://app.db"
})

// 连接池配置
let db = Orion.connect({
  url: "sqlite://app.db",
  pool_size: 10,
  query_timeout: 5000  // 毫秒
})

// 启用日志
Orion.enable_log(db, level: Debug)

// 关闭连接
Orion.close(db)
```

### 事务（v0.2.0+）

```moonbit nocheck
Orion.transaction(db, fn(tx) {
  let user_id = UserMapper.create(tx, "Alice", 25)?
  OrderMapper.create(tx, user_id, 100)?
  Ok(unit)
})
```

### 错误处理

```moonbit nocheck
///|
enum DbError {
  NotFound // 未找到记录
  UniqueViolation // 唯一约束违反
  ConnectionError // 连接错误
  QueryError // 查询错误
  Timeout // 超时
}
```
