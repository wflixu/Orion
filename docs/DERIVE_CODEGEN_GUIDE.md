# Orion v0.2.0 Derive + Codegen ORM 设计指南

> 本文档介绍如何使用 Orion 的 Derive + Codegen 模式，该模式提供类似 Rust SeaORM 的开发体验。

## 概述

Orion v0.2.0 引入了 Derive + Codegen ORM 模式，通过声明式 schema 定义自动生成类型安全的 CRUD 代码。

### 为什么需要 Derive + Codegen？

在 MoonBit 中实现 ORM 面临以下语言限制：

| 限制 | 影响 | Orion 应对方案 |
|------|------|---------------|
| ❌ 不支持用户自定义 derive | 无法 `derive(Entity)` | 外部代码生成器 |
| ❌ 不支持字段级注解 | 无法标注 `@Id`, `@AutoInc` | Schema DSL 中定义 |
| ❌ 不支持运行时反射 | 无法动态读取 schema | 编译时生成代码 |
| ✅ 支持内置 derive | `derive(Eq, Hash, FromJson, ToJson)` | 为生成的 struct 自动添加 |

### 两种开发模式对比

| 维度 | SQL-first (v0.1) | Derive + Codegen (v0.2) |
|------|------------------|-------------------------|
| 定义方式 | SQL 文件 | Schema DSL |
| 代码生成 | 从 SQL 生成 Mapper | 从 Schema 生成 Struct + CRUD |
| 适用场景 | 复杂查询、SQL 可控 | 快速 CRUD、原型开发 |
| 学习曲线 | 需要 SQL 知识 | MoonBit 原生语法 |

## Schema DSL 使用指南

### 基本用法

```moonbit
// schema/user.schema.mbt

import orion/schema

let user_schema = schema("user")
  |> field("id", Int, [PrimaryKey, AutoInc])
  |> field("name", String, [NotNull, MaxLength(100)])
  |> field("email", String, [Unique, NotNull])
  |> field("created_at", String, [Default("CURRENT_TIMESTAMP")])
```

### 约束类型

| 约束 | 描述 | 示例 |
|------|------|------|
| `PrimaryKey` | 主键 | `field("id", Int, [PrimaryKey])` |
| `AutoInc` | 自增 | `field("id", Int, [AutoInc])` |
| `NotNull` | 非空 | `field("name", String, [NotNull])` |
| `Unique` | 唯一 | `field("email", String, [Unique])` |
| `Default(value)` | 默认值 | `field("status", String, [Default("active")])` |
| `MaxLength(n)` | 最大长度 | `field("name", String, [MaxLength(100)])` |
| `Index` | 索引 | `field("email", String, [Index])` |
| `ForeignKey(table, column)` | 外键 | `field("user_id", Int, [ForeignKey("user", "id")])` |

### 定义索引

```moonbit
let user_schema = schema("user")
  |> field("id", Int, [PrimaryKey, AutoInc])
  |> field("email", String, [Unique])
  |> index("idx_email", ["email"])
  |> index("idx_created_at", ["created_at"], unique=false)
```

### 定义关系

```moonbit
// schema/post.schema.mbt

let post_schema = schema("post")
  |> field("id", Int, [PrimaryKey, AutoInc])
  |> field("title", String, [NotNull, MaxLength(200)])
  |> field("content", String, [])
  |> field("author_id", Int, [ForeignKey("user", "id"), NotNull])
  |> field("created_at", String, [Default("CURRENT_TIMESTAMP")])
```

## 生成的代码

### 运行代码生成

```bash
# 生成单个 schema
orion gen schema/user.schema.mbt

# 生成所有 schema
orion gen schema

# 监听模式
orion gen schema --watch
```

### 生成的 Struct

```moonbit
// generated/user.mbt
// @generated by Orion v0.2.0

/// User 数据模型
pub struct User {
  id: Int,
  name: String
} derive(Eq, Hash, FromJson, ToJson, Show)

/// 创建 User 实例（所有字段）
pub fn make_user(id: Int, name: String) -> User {
  User { id, name }
}

/// 创建 User 实例（仅必填字段，自增字段省略）
pub struct CreateUserInput {
  name: String
}

pub fn create_user_input(name: String) -> CreateUserInput {
  CreateUserInput { name }
}
```

### 生成的 CRUD 函数

```moonbit
// generated/user_mapper.mbt
// @generated by Orion v0.2.0

import orion.runtime.{Db, DbError, DbValue}

/// UserMapper 模块
pub struct UserMapper {
  db: Db
}

/// 创建 UserMapper
pub fn new_user_mapper(db: Db) -> UserMapper {
  UserMapper { db }
}

// === CRUD 函数 ===

/// 创建用户
/// @returns 最后插入的 ID
pub fn create_user(self: UserMapper, name: String) -> Result[Int, DbError] {
  let sql = "INSERT INTO user (name) VALUES (?)"
  orion.execute(self.db, sql, [DbValue::String(name)])
}

/// 根据 ID 查找用户
pub fn find_user_by_id(self: UserMapper, id: Int) -> Result[Option[User], DbError] {
  let sql = "SELECT id, name FROM user WHERE id = ?"
  match orion.query(self.db, sql, [DbValue::Int(id)]) {
    Ok(rows) => {
      if rows.length() > 0 {
        Ok(Some(User::from_row(rows[0])))
      } else {
        Ok(None)
      }
    }
    Err(e) => Err(e)
  }
}

/// 查找所有用户
pub fn find_all_users(self: UserMapper) -> Result[List[User], DbError] {
  let sql = "SELECT id, name FROM user"
  match orion.query(self.db, sql, []) {
    Ok(rows) => {
      Ok(rows.map(fn(row) => User::from_row(row)))
    }
    Err(e) => Err(e)
  }
}

/// 更新用户
pub fn update_user(self: UserMapper, id: Int, name: String) -> Result[Int, DbError] {
  let sql = "UPDATE user SET name = ? WHERE id = ?"
  orion.execute(self.db, sql, [DbValue::String(name), DbValue::Int(id)])
}

/// 删除用户
pub fn delete_user_by_id(self: UserMapper, id: Int) -> Result[Int, DbError] {
  let sql = "DELETE FROM user WHERE id = ?"
  orion.execute(self.db, sql, [DbValue::Int(id)])
}
```

### 生成的 Query Builder（可选）

```moonbit
// generated/user_query.mbt
// @generated by Orion v0.2.0

/// User 查询构建器
pub struct UserQuery {
  db: Db
  where_clauses: List[String]
  params: List[DbValue]
  order_by: Option[String]
  limit: Option[Int]
  offset: Option[Int]
}

/// 创建查询构建器
pub fn UserQuery::new(db: Db) -> UserQuery {
  UserQuery {
    db: db,
    where_clauses: [],
    params: [],
    order_by: None,
    limit: None,
    offset: None
  }
}

// === 链式条件方法 ===

/// WHERE id = ?
pub fn UserQuery::where_id(mut self, id: Int) -> Self {
  self.where_clauses.push("id = ?")
  self.params.push(DbValue::Int(id))
  self
}

/// WHERE name = ?
pub fn UserQuery::where_name(mut self, name: String) -> Self {
  self.where_clauses.push("name = ?")
  self.params.push(DbValue::String(name))
  self
}

/// WHERE name LIKE ?
pub fn UserQuery::where_name_contains(mut self, pattern: String) -> Self {
  self.where_clauses.push("name LIKE ?")
  self.params.push(DbValue::String("%" + pattern + "%"))
  self
}

// === 排序和分页 ===

/// ORDER BY id [ASC|DESC]
pub fn UserQuery::order_by_id(mut self, desc: Bool = false) -> Self {
  self.order_by = Some("id " + (if desc { "DESC" } else { "ASC" }))
  self
}

/// LIMIT n
pub fn UserQuery::limit(mut self, n: Int) -> Self {
  self.limit = Some(n)
  self
}

/// OFFSET n
pub fn UserQuery::offset(mut self, n: Int) -> Self {
  self.offset = Some(n)
  self
}

// === 执行方法 ===

/// 执行查询，返回 List[User]
pub fn UserQuery::execute(self) -> Result[List[User], DbError] {
  let mut sql = "SELECT id, name FROM user"
  
  if self.where_clauses.length() > 0 {
    sql = sql + " WHERE " + String::join(self.where_clauses, " AND ")
  }
  
  if self.order_by != None {
    sql = sql + " ORDER BY " + self.order_by.get()
  }
  
  if self.limit != None {
    sql = sql + " LIMIT " + Int::to_string(self.limit.get())
  }
  
  if self.offset != None {
    sql = sql + " OFFSET " + Int::to_string(self.offset.get())
  }
  
  match orion.query(self.db, sql, self.params) {
    Ok(rows) => Ok(rows.map(fn(row) => User::from_row(row)))
    Err(e) => Err(e)
  }
}

/// 执行查询，返回单条结果
pub fn UserQuery::first(self) -> Result[Option[User], DbError] {
  self.limit(1).execute().map(fn(list) => list.head())
}
```

## 使用示例

### 基本 CRUD

```moonbit
import wflixu/Orion
import generated.user_mapper

fn main {
  // 连接数据库
  let db = Orion.connect({
    url: "sqlite://app.db",
    pool_size: 10
  })
  
  // 创建 Mapper
  let user_mapper = UserMapper::new(db)
  
  // 创建用户
  let user_id = user_mapper.create_user("Alice")?
  println("Created user with id: {}", user_id)
  
  // 查找用户
  match user_mapper.find_user_by_id(1) {
    Ok(Some(user)) => println("User: {}", user.name)
    Ok(None) => println("User not found")
    Err(e) => println("Error: {}", e)
  }
  
  // 查找所有用户
  let users = user_mapper.find_all_users()?
  for user in users {
    println("User: {} ({})", user.name, user.id)
  }
  
  // 更新用户
  user_mapper.update_user(1, "Alice Updated")?
  
  // 删除用户
  user_mapper.delete_user_by_id(1)?
}
```

### 使用 Query Builder

```moonbit
import wflixu/Orion
import generated.user_query

fn main {
  let db = Orion.connect({ url: "sqlite://app.db" })
  
  // 链式查询
  let users = UserQuery::new(db)
    |> UserQuery::where_name_contains("alice")
    |> UserQuery::order_by_id(desc=true)
    |> UserQuery::limit(10)
    |> UserQuery::execute()
  
  for user in users? {
    println("User: {}", user.name)
  }
  
  // 查询单条
  let user = UserQuery::new(db)
    |> UserQuery::where_id(1)
    |> UserQuery::first()
  
  match user? {
    Some(u) => println("Found: {}", u.name)
    None => println("Not found")
  }
}
```

### 事务支持

```moonbit
import wflixu/Orion

fn main {
  let db = Orion.connect({ url: "sqlite://app.db" })
  
  // 事务中执行多个操作
  Orion.transaction(db, fn() {
    let user_id = UserMapper::new(db).create_user("Bob")?
    PostMapper::new(db).create(user_id, "Hello World", "Content here...")?

  })
```

## 最佳实践

### 1. Schema 命名约定

```moonbit
// 推荐：使用单数名词，帕斯卡命名
let user_schema = schema("user")
let post_schema = schema("post")

// 推荐：字段使用蛇形命名
field("created_at", String, [])
field("user_id", Int, [])
```

### 2. 约束定义

```moonbit
// 推荐：明确定义所有约束
let user_schema = schema("user")
  |> field("id", Int, [PrimaryKey, AutoInc])
  |> field("email", String, [Unique, NotNull, MaxLength(255)])
  |> field("name", String, [NotNull, MaxLength(100)])
  |> field("created_at", String, [Default("CURRENT_TIMESTAMP")])

// 不推荐：约束定义不完整
let user_schema = schema("user")
  |> field("id", Int, [])  // 缺少 PrimaryKey
  |> field("email", String, [])  // 缺少 Unique
```

### 3. 代码生成策略

```bash
# 推荐：将生成的代码放入独立目录
orion gen schema --output generated

# 推荐：在 .gitignore 中排除生成的代码
echo "generated/" >> .gitignore

# 或者：提交生成的代码以便审查
# 添加 @generated 标记
```

### 4. 自定义扩展

```moonbit
// 推荐：在生成的代码基础上手动扩展
// generated/user_ext.mbt（手写文件）

import generated.user_mapper

/// 扩展 UserMapper 的自定义方法
pub fn find_users_by_email_domain(
  mapper: UserMapper,
  domain: String
) -> Result[List[User], DbError] {
  let sql = "SELECT * FROM user WHERE email LIKE ?"
  orion.query(mapper.db, sql, [DbValue::String("%@" + domain)])
}
```

## 常见问题 (FAQ)

### Q: Schema DSL 和 SQL-first 模式可以同时使用吗？

A: 可以。Orion v0.2.0 支持两种模式共存：

```bash
# SQL-first 模式
orion gen queries

# Derive + Codegen 模式
orion gen schema
```

### Q: 如何自定义生成的代码？

A: 有两种方式：
1. 在生成的代码基础上手动扩展（推荐）
2. 使用自定义模板（v0.3.0+）

### Q: 如何迁移现有数据库？

A: 使用 `orion pull` 命令（v0.4.0+）：

```bash
orion pull --url sqlite://app.db --output schema
```

### Q: 支持哪些数据库？

A: 
- SQLite ✅ (v0.1.0)
- PostgreSQL 🔄 (v0.2.0)
- MySQL 📅 (v0.3.0)
